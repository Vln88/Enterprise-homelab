# OPNsense

OPNsense is used as the firewall and router of the laboratory.

## Role

- Network routing
- Firewall
- Internet gateway
- Traffic logging
- Network security

## Network

| Parameter | Value |
|---|---|
| LAN IP | 192.168.88.1 |
| Network | 192.168.88.0/24 |

## Firewall

The laboratory uses OPNsense firewall policies to control network traffic.

WAN inbound traffic is blocked by default.

LAN traffic is currently allowed for the laboratory environment.

## Logging

OPNsense Live View was used to verify and monitor traffic generated by laboratory machines.

## Validation

Tested traffic includes:

- Windows clients → Windows Server
- Windows clients → Debian
- Debian → OPNsense
- Debian → Internet
